RR Academy Admin + CBT Android V3 — Termux upload

Open Termux and run (separately from the fee-management project):
  cd ~/rr-admin-v3
  gh auth setup-git
  git clone https://github.com/rrdefenceacademy2-create/rr-academy-admin.git .
  unzip -o ~/storage/downloads/RR_Academy_Admin_CBT_V3_Fresh_Source.zip -d .
  git config user.name "RR Defence Academy"
  git config user.email "rrdefenceacademy2-create@users.noreply.github.com"
  git add .
  git commit -m "Add Android Admin CBT V3"
  git push origin main

After push, visit https://github.com/rrdefenceacademy2-create/rr-academy-admin/actions
